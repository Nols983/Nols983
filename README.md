## Azubi Lab

Mein aktuelles Hauptprojekt ist **Azubi Lab**, eine selbst gehostete Lernplattform für Fachinformatiker Systemintegration.

Die Plattform verbindet Lerninhalte, Quizze und interaktive Troubleshooting-Labs mit einer eigenen Linux-, Container-, Datenbank-, Deployment- und Backup-Infrastruktur.
